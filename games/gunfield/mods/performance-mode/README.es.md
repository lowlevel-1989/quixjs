# performance-mode

Más rápido con muchos enemigos en pantalla: los objetos que llevan dos
efectos de color a la vez, o un efecto con transparencia, se dibujan sin
ellos (en una handheld cada uno se dibuja aparte y cuesta más que el resto de
la imagen). Se pierden algunos colores: el destello de un enemigo al recibir
un golpe, el tinte de algunas plataformas.

Viene activado. Para quitarlo: `performance-mode: Off` en la opción Mods del launcher
del port.
