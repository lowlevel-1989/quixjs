# achievements

The pause (Start) shows the achievements: each one with the square of its
color, full if you have it and empty if not, and below the description of
the chosen one. Up and down choose; Start goes on playing.

It comes on. To turn it off: `achievements: Off` in the Mods option of the
menu of the port (the pause is then the usual "Game paused").
