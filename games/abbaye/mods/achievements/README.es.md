# achievements

La pausa (Start) muestra los logros: cada uno con el cuadrado de su color,
lleno si lo tienes y hueco si no, y abajo la descripción del elegido. Arriba
y abajo eligen; Start sigue jugando.

Viene activado. Para quitarlo: `achievements: Off` en la opción Mods del menú
del port (la pausa vuelve a ser el "Game paused" de siempre).
