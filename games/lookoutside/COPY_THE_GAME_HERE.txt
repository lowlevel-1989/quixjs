Copy the game here, next to port.toml.

You need Look Outside 2.3 for Windows (GOG or Steam).
Compress the folder of the game (Look Outside, the one with data/ and
js/) into a zip (on Windows: right click on it, Send to, Compressed
(zipped) folder): you get Look Outside.zip. Copy that zip here:

lookoutside/
  port.toml
  Look Outside.zip

A zip without compression is best (with 7-Zip: Compression level, Store);
a compressed one also works, but the first start takes longer.
If your file has another name, write it in port.toml, in
rom = "Look Outside.zip".
See README.md for the full steps.
