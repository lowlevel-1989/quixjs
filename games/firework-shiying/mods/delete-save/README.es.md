# delete-save

Borrar una partida desde las pantallas de guardar y cargar: pulsa X sobre
una partida y se pone en rojo con "X: delete?"; pulsa X otra vez y se borra.
A, B o moverse la
dejan como estaba (A no la carga). En la pantalla de cargar, A sobre una
casilla vacía empieza una partida nueva. Junto a la leyenda de la pantalla
dice "X Delete".

Viene activado. Para quitarlo: `delete-save: Off` en la opción Mods del menú
del port.
