# delete-save

Delete a save from the save and load screens: press X on a save and it turns
red with "X: delete?"; press X again and it is deleted. A, B or moving
leaves it as it was (A does not load it). On the load screen, A on an empty
slot starts a new game. Next to the legend of the screen it says "X Delete".

It comes on. To turn it off: `delete-save: Off` in the Mods option of the
menu of the port.
