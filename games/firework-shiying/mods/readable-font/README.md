# readable-font

The text with M+ 1m, the RPG Maker font that comes with the game, easier to
read on a small screen than the font of the game. It takes the same space, so
the dialogues break their lines the same way.

It comes on. To turn it off: `readable-font: Off` in the Mods option of the
launcher of the port.
