# readable-font

El texto con M+ 1m, la fuente de RPG Maker que trae el juego, más fácil de
leer en una pantalla pequeña que la del juego. Ocupa lo mismo, así que los
diálogos cortan las líneas igual.

Viene encendido. Para apagarlo: `readable-font: Off` en la opción Mods del
launcher del port.
