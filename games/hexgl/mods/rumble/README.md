# rumble

The handheld vibrates when the ship hits a wall (`impact`), when it is
destroyed (`heavy-impact`) and on a boost pad (`tick`). Only on devices with
a motor.

It comes on. To turn it off: Options > Vibration: Off, or `rumble: Off` in
the Mods option of the launcher of the port.
