Copy the game here, next to port.toml.

You need HexGL, a free game by Thibaut Despoulain (BKcore). Open its repository at the
version this port uses and download it with Code, Download ZIP:
https://github.com/BKcore/HexGL/tree/6addc95a2fce3bf05f4d751823cc054c61a16d68

Copy that zip here as it is, without unzipping it:

hexgl/
  port.toml
  HexGL-6addc95a2fce3bf05f4d751823cc054c61a16d68.zip

If your file has another name, write it in port.toml, in
rom = "HexGL-6addc95a2fce3bf05f4d751823cc054c61a16d68.zip".
See README.md for the full steps.
