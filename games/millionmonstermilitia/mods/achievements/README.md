# achievements

Start opens the list of achievements at any moment of the game: each one with
the square of its color, filled if you have it and hollow if not, and below
the description of the chosen one. Up and down choose, left and right turn
the page; Start or B go back to the game. While it is open, the game stops.

Start can be moved to another button in the Controls option of the launcher
of the port ("Achievements").

It is on. To remove it: `achievements: Off` in the Mods option of the
launcher of the port.
