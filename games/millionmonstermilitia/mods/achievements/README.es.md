# achievements

Start abre la lista de los logros en cualquier momento de la partida: cada
uno con el cuadrado de su color, lleno si lo tienes y hueco si no, y abajo la
descripción del elegido. Arriba y abajo eligen, izquierda y derecha pasan
página; Start o B vuelven al juego. Mientras está abierta, el juego se para.

Start se puede cambiar de botón en la opción Controls del launcher del port
("Achievements").

Viene activado. Para quitarlo: `achievements: Off` en la opción Mods del
launcher del port.
