# reader

R1 opens, over the game, the texts on the screen with a large and easy to
read font (DejaVu Sans Bold). The game keeps its own font; only the reader
uses this one.

- With the cursor on a card (when choosing recruits), it reads only that
  card. Left and right go to the next card.
- On another screen, all the texts that are shown, from top to bottom.

Up and down scroll the text if it does not fit; R1 or B go back to the game.
While it is open, the game stops.

R1 can be moved to another button in the Controls option of the launcher of
the port ("Reader").

It is on. To remove it: `reader: Off` in the Mods option of the launcher of
the port.
