# controller

Play with a gamepad, like in Tamatama: the d-pad moves the cursor between
what can be pressed on the screen and A presses it. On the board the
selected tile is colored and the d-pad is turned 45 degrees (up goes
up-right, right goes down-right, down goes down-left, left goes up-left).
When A opens a window, the cursor goes into it, and B closes it.

It comes on. To remove it: `controller: Off` in the Mods option of the
launcher of the port.
