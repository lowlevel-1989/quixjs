Copy the game here, next to port.toml.

You need Muffles' Life Sentence for Windows (Steam).
In the folder of the game (in Steam: right click on the game, Manage,
Browse local files), compress its folder www into a zip named www.zip
(on Windows: right click on www, Send to, Compressed (zipped) folder),
and copy that zip here:

muffleslifesentence/
  port.toml
  www.zip

A zip without compression is best (with 7-Zip: Compression level, Store);
a compressed one also works, but the first start takes longer.
If your file has another name, write it in port.toml, in
rom = "www.zip".
See README.md for the full steps.
